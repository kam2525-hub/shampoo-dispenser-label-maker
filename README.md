# お風呂のシャンプー見分けつかない問題解消！ボトル識別ラベル一括ジェネレーター

水に濡れても滲まない、家族みんながパッと見で区別できるオリジナル浴室ボトル用ラベルをデザイン・印刷できるツール

## 🌟 主な特徴
- **完全フロントエンド完結**: サーバー不要でブラウザを開くだけで即座に動作。
- **安心・安全**: データはブラウザのローカル環境のみで処理され、外部への通信は行いません。
- **モバイル対応**: スマートフォン・PCのどちらでも直感的に使えるレスポンシブ設計。

## 🚀 使い方
1. リポジトリ内の `index.html` をブラウザで開きます（または GitHub Pages でアクセス: https://kam2525-hub.github.io/shampoo-dispenser-label-maker/）。
2. 画面の指示に従って操作します。
